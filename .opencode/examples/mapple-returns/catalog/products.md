# Mapple product catalog

Only these nine variations are valid for the guarantee return flow. Storage
capacity, size, and finish are part of the product identity.

A model name without a size is ambiguous when two rows share it. In that case the
intake agent reports `UNKNOWN_PRODUCT` and asks for the exact variation.
